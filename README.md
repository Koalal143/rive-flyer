# RiveGaucheMVP

Адаптивный лендинг учебной акции. Фронтенд на React и Vite расположен
в `frontend/`. Папка `backend/` зарезервирована для будущего FastAPI.

## Разработка и сборка

Нужен Node.js 22.12+.

```sh
cd frontend
npm ci
npm run dev
```

`npm run build` создаёт статическую сборку в `frontend/dist/`.
Проверить сборку можно через `npm run preview`.

## Docker

```sh
docker build -t rivegauche-mvp .
docker run --rm -p 8080:80 rivegauche-mvp
```

## Данные проекта

В витрине используются фото с оригинальных страниц РИВ ГОШ и цены из
материалов проекта. Цены в участвующих магазинах требуют сверки перед пилотом.
Фото стакана и бальзама на первом экране предоставлены для учебного проекта.
Демо-карта показывает условные точки и остатки.
