# RiveGaucheMVP

Адаптивный лендинг учебной акции. Фронтенд на React и Vite находится
в `frontend/`, сервер поиска магазинов на FastAPI — в `backend/`.

## Яндекс Карты

В [Кабинете разработчика Яндекса](https://developer.tech.yandex.ru/) создайте два ключа.

- **JavaScript API** — для интерактивной карты. Укажите `localhost` для локальной
  разработки и домен будущего сайта в ограничении по HTTP Referer.
- **API Поиска по организациям** — для серверного поиска ближайшего РИВ ГОШ.
  Этот ключ остаётся на сервере.

Ключи указываются в локальном `.env`. Если файла ещё нет, создайте его из шаблона.

```sh
cp -n .env.example .env
```

Заполните `YANDEX_MAPS_API_KEY` и `YANDEX_SEARCH_API_KEY`. Ключ JavaScript API
будет доступен браузеру, поэтому ограничение по домену обязательно.

## Запуск через Docker

```sh
docker compose up --build
```

Откройте http://localhost. Compose передаёт ключи в FastAPI, а Nginx
проксирует запросы `/api/`. Без ключей поиск работает по резервному каталогу,
а адрес можно открыть во внешних Яндекс Картах.

## Локальная разработка

Требуется Python 3.10+ и Node.js 22.12+. Из корня проекта:

```sh
python3 -m venv backend/.venv
backend/.venv/bin/pip install -r backend/requirements.txt -r backend/analytics-requirements.txt
set -a
. ./.env
set +a
backend/.venv/bin/uvicorn main:app --app-dir backend --reload --port 8000
```

В другом терминале:

```sh
npm --prefix frontend ci
npm --prefix frontend run dev
```

Откройте http://localhost:5173. Для геолокации на публичном сайте нужен HTTPS.
Стрелка в блоке «Ближайший магазин» сразу запрашивает геолокацию.

Сервер ранжирует магазины по расстоянию по прямой. Адрес выводится в карточке
магазина и на метке карты. Для поиска Яндекс
получает координаты, округлённые до трёх знаков после запятой. Бэкенд
не сохраняет местоположение. Раздел показывает магазины сети.
Подтверждённые места выдачи подарка определяются отдельно.

### Каталог и остатки подарков

FastAPI может искать ближайшую точку по локальному JSON без вызовов API Поиска
по организациям. Для Docker положите файл в `backend/data/stores.json`, задайте
`STORE_CATALOG_PATH=/app/data/stores.json` в `.env` и запустите Compose. При локальном
запуске укажите абсолютный путь к файлу. При пустом `STORE_CATALOG_PATH` включается
поиск по организациям Яндекса.

Каталог — массив объектов с обязательными полями `name`, `latitude`, `longitude`
и необязательными `address`, `hours`, `gift_stock`. В `gift_stock` указывается
подтверждённый остаток подарков акции в магазине. Положительное целое число
показывает «Есть подарок», `0` — «Подарки закончились», `null` или пропущенное
поле — «Наличие не подтверждено». Статус виден в результате поиска и на маркере.
Чтобы загрузить обновлённые остатки из файла, перезапустите FastAPI.

`backend/data/stores-catalog.json` содержит 238 магазинов с адресами и координатами
на 23 ноября 2026 года. Список магазинов собран по ноябрьской акции и карточкам
РИВ ГОШ. Полнота относительно всей сети не подтверждена. Для каждой записи
указаны источники адреса и координат. Часть координат относится к зданию
торгового центра. Данные OpenStreetMap доступны по лицензии ODbL.

FastAPI использует этот каталог как резерв при недоступности Поиска Яндекса,
в пределах 150 км от пользователя. Для пилота добавьте подтверждённые остатки
подарков в локальный каталог подключённых магазинов.

## Данные витрины

В витрине используются фото с оригинальных страниц РИВ ГОШ и цены из
материалов проекта. Цены в участвующих магазинах требуют сверки перед пилотом.
Фото стакана и бальзама на первом экране предоставлены для учебного проекта.

## Метрики пилота

После `docker compose up -d --build` откройте
[дашборд Grafana](http://localhost:3010/d/rivegauche-pilot). Он настраивается
при запуске, обновляется раз в 30 секунд и показывает последние семь дней.
Grafana доступна локально в режиме просмотра. Порт можно задать через
`GRAFANA_PORT`. События сохраняются в томе `analytics-data` PostgreSQL.

Для каждого бумажного флаера используйте свой адрес вида
`https://домен-лендинга/?qr=RG-A001`. Идентификатор может содержать до 100
латинских букв, цифр, дефисов и подчёркиваний. В аналитической базе хранится
хеш кода. Прямые визиты учитываются отдельно от визитов по QR.

| Метрика | Что учитывается |
| --- | --- |
| Переходы по QR | Визиты по ссылке с параметром `qr` и разные коды за период. Один код может привести к нескольким визитам. |
| Активное время | Медиана по визитам с замером. Время отправляется каждые 15 секунд и при уходе со страницы. Учитывается только видимая вкладка. |
| Просмотры товаров | Показ от половины изображения подарка или мини-карточки в течение 750 мс. В таблице отдельно учитываются открытые страницы товаров. Показ и открытие считаются один раз на товар за визит. |
| Клики на сайт РИВ ГОШ | Клики по ссылкам на официальный сайт, включая оригинальные страницы товаров. |
| Клики на приложения | Клики на страницы приложения в App Store, Google Play и RuStore с разбивкой по магазину. |

Визит привязан к вкладке и сохраняется при переходах между страницами. При
новой загрузке после 30 минут паузы или открытии ссылки с другим QR начинается
новый визит. Данные о покупках, установках и выдаче подарков потребуют
отдельного источника.

### Графики по дням

Дашборд показывает визиты и переходы по QR, медиану активного времени,
просмотры и открытия товаров, а также клики на сайт и в магазины приложений.
Календарные дни считаются по московскому времени. Дни без событий показаны
нулём на графиках количества. Если замеров времени нет, линия медианы
прерывается.

## Production

Скопируйте `.env.prod.example` в `.env.prod` и задайте три разных пароля.
Используйте Docker Compose версии 2.24.4 или новее.

```sh
docker compose --env-file .env.prod -f compose.yaml -f compose.prod.yaml up -d --build
```

Продакшен запускается как отдельный проект `rivegauche-prod` со своими
томами PostgreSQL и Grafana. Сервис `nginx` отдаёт сборку фронтенда, проксирует
`/api/` в FastAPI и выставляет длительный кеш для ресурсов с хешем из
`/assets/`. Nginx публикует HTTP на порту 80 сервера и отдаёт лендинг
пока запускается FastAPI. Порт 80 должен быть свободен на хосте и открыт
для входящих подключений. HTTPS на домене потребуется для геолокации
в браузере.

Grafana слушает `127.0.0.1:3011`. Войдите как `admin` с паролем
`GRAFANA_ADMIN_PASSWORD`, заданным до первого запуска.
