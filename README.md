# RiveGaucheMVP

Адаптивный лендинг учебной акции. Изображения, стили и сценарии хранятся
в `frontend/`. Папка `backend/` зарезервирована для будущего FastAPI.

## Просмотр

Можно открыть `frontend/index.html` в браузере или запустить сервер из корня проекта.

```sh
python3 -m http.server 8080 --directory frontend
```

Откройте http://localhost:8080.

## Docker

```sh
docker build -t rivegauche-mvp .
docker run --rm -p 8080:80 rivegauche-mvp
```

## Данные проекта

Карточки используют цены из предоставленных макетов и прямые ссылки на РИВ ГОШ.
Цены в участвующих магазинах требуют сверки перед пилотом.
Демо-карта использует условные точки и остатки. Погашение QR-кодов и сбор аналитики
относятся к следующему этапу разработки. Изображения кофе и товаров предоставлены
для учебного проекта. На стакане видна маркировка Starbucks.

Визуальные референсы: официальный каталог РИВ ГОШ и публичный кейс айдентики
Profilaktika. Доступного полного брендбука в предоставленных материалах нет.
